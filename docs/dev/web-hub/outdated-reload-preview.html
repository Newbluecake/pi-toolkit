交互预览（静态 HTML，按钮可点）。配色 / 圆角 / 字号 / 按钮沿用 web-hub 现有 tokens 与 primitives（notice / btn / chip / pill）。每节右上角「重置」可重放该节。

1 · 会话详情页顶部提示条（推荐主方案）

进入落后会话的详情页，顶部出现 warning 提示条。点【重新加载】→「正在重新加载…」→ 成功后提示条消失，短暂出现「已重新加载到 0.9.0」通知。点【暂不】见第 4 节。

2 · 会话忙（正在运行）时排队

3 · 重新加载失败

命令通道失败（如会话进程已退出 / 连接断开）时，提示条转为 danger 态，给出原因与【重试】【关闭】。（预览里「重试」会演示一次成功重载。）

提示条收起，侧边栏卡片上的 outdated 标记（info 图标 pill「插件旧于 hub，需 /reload」）保留；hub 版本再次变化前不再提示。

5 · 侧边栏会话卡片标记更醒目

落后会话的卡片在原有 info 图标之外加一枚小号「需更新」徽章（chip 形，warning 配色）。点击卡片进入详情页即看到第 1 节的提示条（预览里点击会滚动并高亮第 1 节）。
