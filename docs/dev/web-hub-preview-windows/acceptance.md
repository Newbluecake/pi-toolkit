# web-hub 文件预览多窗口 · 真机验收清单（preview-windows plan r2 §14）

对应施工方案：`docs/dev/web-hub-preview-windows/plan.md`（r2 + §15 拍板 + r2 复审结论）。
条目编号与 plan §14 一致：**D1–D11** 桌面、**P12–P15** 手机、**J16** 联合验收；每条给出
**操作 → 预期 → 取证**，全部是可判定的通过标准（无「大致正常」类措辞）。

自动化测试（`tests/web-hub/ui/preview-windows*.test.ts`、`preview-window-cycle.test.ts`、
`preview-html.test.ts` 等）已钉住路由/几何/焦点/账本的逻辑；本清单验的是**真机上端到端的
人感**（拖动手感、inert、IME、层级遮挡、内存），两者互补（plan R8：inert 与手感靠真机）。

## 通用前置

- hub 机：`pi` + pi-toolkit，`webHub.enabled` 且 `webHub.preview` 非 off；浏览器打开 web UI
  并进入一个 agent 详情会话。
- 桌面浏览器：Chrome 与 Firefox 各完整跑一遍 D1–D11（发现布局/输入法差异时再加 Safari）；
  视口 ≥768px（建议 1280×800 与 768×900 各一轮，后者贴着断点）。
- 手机：iOS Safari 与 Android Chrome 各完整跑一遍 P12–P15，经 LAN 密码登录，竖屏
  （viewport <768px）；P14 需可旋转或可旋转的平板。
- 造数据（建议放同一个临时目录，如 `/tmp/pw-acc/`）：
  - 文本 `a.txt`、`b.md`（md 内含指向同目录文件的绝对路径与目录链接）、子目录 `src/`
    （含 `x.ts`、一个指向目录的 symlink `dlink` 与指向文件的 symlink `flink`）；
  - HTML 入口 `site/index.html`：页内放指向同目录 `sib.txt` 的 `<a href="sib.txt">` 与
    `fetch("sib.txt")` 的脚本输出区（D9 判定「链接失败/恢复」用）；
  - 宽 mermaid 的 `wide.md`：一个 `flowchart LR` 长链（≥30 个节点，自然宽度明显超过窗口；
    J16 用）；
  - ≈40 MP 图片若干（如 7000×5715 PNG，D11/P15 用；可用 ImageMagick
    `magick -size 7000x5715 gradient:red-blue big1.png` 批量生成 40 张不同文件名）。
- 让会话消息里出现这些**绝对路径**（settled 消息，PathText 探测确认后可点）。
- 取证工具：截图/录屏；devtools 的 Network（iframe/DOMContentLoaded、`/api/preview`、
  `html-cap`）与 Console；Chrome 任务管理器（内存峰值）；iOS 可用 Mac 的 Safari 远程检查。
