新语义下 AI 创建/修改的定时任务自动批准、立即生效，不再有批准页。 聚合原则：定时任务与 Todo 在 detail 面板与输入框左上角 chip 分区同屏；运行实例仍跳 subagent/fleet 详情，不混成 todo。 紧凑标记（chip / 状态 / 时间）用英文 token，说明性文字用中文。

A · 推荐：detail 统一 TasksPanel（Todo 分区 + 定时任务分区）

一条合并 summary（Tasks 3/8 · 2 active · ⏰ 2）作为扫视面；展开后两个分区。 定时任务分区每行：名称 · when 文本 · next 相对时间 · 状态 chip（running / paused）· 最近 run（可点跳 fleet）。 操作列：暂停/继续、删除。分区尾部「详情 »」打开既有 SchedulePanel 全功能对话框。
