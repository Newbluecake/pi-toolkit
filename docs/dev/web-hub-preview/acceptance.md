> 配套：`plan.md`（v3 最终版）。本文是 preview 线（PV1–PV8）的交付物之一。
> plan §6 各包验收与 §6.1 HP1–HP8 已由 PV1–PV7 的自动化测试落地全绿（§0.5）；本文的 A/B/C 系列是
> **真机终裁**清单——桌面浏览器 + 手机 LAN，人能照做：每条给出操作步骤、预期现象与超时上限。

已知实现口径（非缺陷，验收时按此判读）：

- 上传附件内容对**会话可见者共享**（U3）：同一会话的任何已认证读者都能预览，与「仅上传者」的旧裁定
  相反——已由用户拍板并写进 upload plan 文末修订备注与 `lan-plan.md`。
- 预览读取**不钉住、不延长**附件 TTL（`referencedAt` 不动）：被淘汰后点开是「预览失败」（404）。
- hardlink 指向 cwd 外的文件**会**被预览（不在威胁模型内，单测钉住）；`mode:"loopback"` 下 LAN 返回
  404 而非 403，与 off 字节一致（D12）。
- http(s) 链接仍是纯链接，**没有** unfurl 预览卡（用户已否）；SVG 不作为图片预览（按文本处理）。

## 1. 前置条件（每轮验收开始前）

1. 隔离环境（可选但推荐）：`export HOME=$(mktemp -d /tmp/pwh-pv-acc-XXXX)`；否则用日常 HOME 时注意 §C4。
2. 正规安装本包（**禁止 `pi -e`**，理由同 spawn acceptance §1）：`pi install /home/bluecake/ai/pi-toolkit`。
3. `~/.pi/agent/pi-subagent.json`：

   ```json
   {
     "webHub": {
       "enabled": true,
       "lan": { "enabled": true },
       "preview": "on"
     }
   }
   ```

   `preview` 默认即 `"on"`（U1），显式写出便于 B7 来回切换。改 mode 后需 `/reload` + `/webhub restart`。

4. 建验收目录与素材（在将作为会话 cwd 的目录里执行；PNG 生成脚本 ~2s，无需 ImageMagick）：

   ```sh
   mkdir -p ~/acc-pv && cd ~/acc-pv
   printf 'preview acceptance\nline2 Δ中文Δ\n' > acc-note.txt
   cp /usr/share/backgrounds/*.png acc-photo.png 2>/dev/null || cp "$(ls /usr/share/pixmaps/*.png 2>/dev/null | head -1)" acc-photo.png 2>/dev/null || true
   python3 - <<'PY'
   import struct, zlib, os
   def png(path, w, h, noise=False):
       raw = (b"".join(b"\x00" + os.urandom(w * 3) for _ in range(h)) if noise
              else (b"\x00" + bytes([0x80]) * (w * 3)) * h)
       def chunk(t, d):
           return struct.pack(">I", len(d)) + t + d + struct.pack(">I", zlib.crc32(t + d) & 0xFFFFFFFF)
       hdr = struct.pack(">IIBBBBB", w, h, 8, 2, 0, 0, 0)
       open(path, "wb").write(b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", hdr)
                              + chunk(b"IDAT", zlib.compress(raw, 6)) + chunk(b"IEND", b""))
   png("acc-4mib-under.png", 1300, 1054, True)   # ≈3.92 MiB / 1.37 MP：LAN 上限内
   png("acc-4mib-over.png", 1330, 1070, True)    # ≈4.07 MiB：超 LAN 4 MiB、未超 loopback 16 MiB
   png("acc-25mp.png", 5000, 5000)               # 25 MP / ≈86 KB：未超服务端 40 MP，超触屏 20 MP
   png("acc-42mp.png", 6500, 6500)               # 42.25 MP：超服务端 40 MP
   open("acc-big.txt", "w").write(("预览验收Δ日本語ΔΔ" + "x" * 80 + "\n") * 2400)  # ≈263 KB > 256 KiB
   open("acc-fake.png", "wb").write(b"\x89PNG\r\n\x1a\n" + b"\x00" * 4096)          # 魔数对、尺寸解析不出
   png("acc-photo.png", 800, 600, True)          # 兜底：上面 cp 不到素材时生成一张噪声图
   PY
   printf '\x00\x01\x02binary\xff' > acc-bin.dat
   ```

5. 启动宿主：`tmux new-session -d -s pwhpv -x 220 -y 55 -c ~/acc-pv "pi"`；LAN 需 `/webhub passwd` 建两个
   用户 `ua`、`ub`。`/webhub open` 取 loopback URL；LAN URL 为 `http://<内网IP>:<webHub.lan.port>`。
6. 确认 caps（桌面 DevTools 看 SSE `hub` 帧）：`caps` 含 `preview.v1` 与 `preview.lan.v1`（mode on 的两处
   声明一致）；手机端登录后同样可见。
7. 记基线进程与端口：`pgrep -u $USER -fa 'pi|node' > /tmp/pwh-pv-base.txt`。
