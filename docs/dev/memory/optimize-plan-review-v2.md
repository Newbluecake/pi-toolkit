## 决策

- **用户（2026-09-26）**：N1 = 无价格模型 tidy **允许 + 警告**（仍保留 turns / outputBytes / timeout 硬上限；UI/报告明确「无成本保证」）；N2 = 全部路径（含 legacy）拒绝**文件级**符号链接；N3 = 模型不能改手写文件 frontmatter。
