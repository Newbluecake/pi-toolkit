## D1–D7 逐项意见

- **D1 同意推荐 (a)**：实测 0.8–1.1s 对 1.5s 预算有足够余量，召回是主通道就不该纯异步。

- **D4 同意推荐 (a)，附条件**：必须补首次 ready 的一次性通知（问题 #2），否则「自动启用」变成「静默外发」。

- **D6 同意推荐 (a)**：每次 $0.004 且只提示不动数据，正是「GPT 禁用留 8 天」的针对性解药；corpusFp 扫描成本可忽略。
- **D7 同意推荐 (a)，附两个条件**：① 进程 cmdline 必须过 §7 脱敏管线（架构已含，需在 C-J/集成测试里钉一条断言）；② 文档声明非 Linux 退化或补 `ps` 兜底（问题 #3）。secure README 的 R16（同 uid 本就可读 `/proc/<pid>/mem`）证明边际风险只在「外发」，而「规则正文点名才收录」的过滤器把这个风险压到了合理水平。
