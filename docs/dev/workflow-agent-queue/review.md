## 已核查成立的断言

- stopOwned / onTerminating 均先置 `terminated` 再 `cancelAll`，pump 不会在停止中途派发；`onHostCall` 入口有 terminated 拒绝。
- `recordSettled` 是唯一结算汇聚点；live 路径先 `registry.settle` 再 record，pump 计数不会多算。
- `deriveChildBudget` 的 `deadlineAt ≡ min(workflow, phase) 截止`，与 policy 无关；phaseDeadlineAt 现未接线。
- worker：ack 即清 HR1；`waitForSettle` 界限 `deadlineAt-now+5s`；`bufferedSettles` 5s TTL 且当前不透传 rejected；心跳为 unref 的 setInterval；scriptSliceMs 只限同步切片。
- 默认值 maxChildren=500、maxParallel=`max(1,min(4,concurrencyLimit-1))` 准确。
- 两个既有缺陷属实：phase 计时器忽略 `registry.cancel` 返回值（host.ts:306-312）；stopOwned 期间 in-flight spawn 返回 error 无守卫双记录（host.ts:604-616）。
- journal：occurrence 与 chainDigest 在提交时分配（host.ts:462-476），排队不破坏「至多复用一次」。
